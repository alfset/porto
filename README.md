# Alfset Portfolio

Personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

```bash
npm ci
npm run dev
```

Run `npm run build` to validate the production build, then `npm start` to serve it.

The Security Findings section is maintained in `components/SecurityFindings.tsx`.
It includes the [published XGR advisory](https://github.com/xgr-network/xgr-node/security/advisories/GHSA-rhv3-x676-72g9),
which credits `alfset` as reporter, and an author-provided summary of the ABEY
report for `AbeyFoundation/go-abey` at `b74a6e8` (v3.4.9). ABEY severity and devnet
results are attributed to the submitted report; no public advisory, maintainer
confirmation, or fix status is claimed. Private correspondence and attachments
are not included.
